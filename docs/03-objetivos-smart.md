# Objetivos SMART

## Objetivos

1. Implementar para la entrega final un prototipo Android con login, catálogo, reserva, edición, cancelación, búsqueda, SQLite y validación.
2. Publicar para la defensa una API REST con autenticación, catálogo, citas y CRUD administrativo; verificarla con pruebas de aislamiento, idempotencia, conflicto y estados.
3. Entregar informe, modelo de datos, flujos, manuales, matriz y una demostración de tres a cinco minutos.

## Medición

- Build Android y pruebas unitarias aprobadas.
- Cuatro suites backend aprobadas.
- Endpoint de salud público.
- Flujo de reserva visible en emulador y portal.
- Campos de equipo completados antes de presentar.
