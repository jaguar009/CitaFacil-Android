# Manifiesto de reproducibilidad de CitaFácil

Fecha de generación: 21 de septiembre de 2026.

## Evidencia técnica

- API publicada: https://citafacil.jaguar009.workers.dev
- Panel administrativo: https://citafacil.jaguar009.workers.dev/admin.html
- Proyecto Android: Java 11, Android SDK API 37, paquete `com.example.myapplication`.
- Base remota: Cloudflare D1 `citafacil-academico`.
- Pruebas backend: 4 suites aprobadas con `npm test`.
- Build Android: `assembleDebug` y `testDebugUnitTest` aprobados.
- Demo MP4: 3 minutos 27 segundos, capturada en Pixel 10 Pro XL.

## Trazabilidad de artefactos

El APK, el código fuente comprimido, el esquema SQL, los manuales, los diagramas y el informe se generan desde el proyecto compartido. El código fuente excluye credenciales, bases locales y dependencias instaladas.

La implementación fue realizada con asistencia de Codex. Este manifiesto no sustituye la autoría académica: el equipo debe completar la carátula, indicar los nombres reales y registrar qué integrante revisó, comprendió y presentó cada parte. No se deben inventar commits, nombres ni aportes.
